# VotoElectronicoAES

## Requisitos

Python 3 y la dependencia `pycryptodome`.

Instala las dependencias en el mismo intérprete de Python que usa VS Code:

```bash
python -m pip install -r requirements.txt
```

En VS Code, selecciona ese intérprete con **Python: Select Interpreter** y
ejecuta `main.py` con **Run Python File**. También puedes iniciar la aplicación
desde la terminal:

```bash
python main.py
```
